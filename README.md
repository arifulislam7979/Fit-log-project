Project Summary

Project Name: FITLOG

Short Description: 
A modern, dark-themed workout tracking web app designed to help users structure, organize, and execute their daily fitness routines with real-time stat calculations.

Technologies Used: 
  vite (project setup),
  Next.js (App Router),
  React, 
  TypeScript, 
  Tailwind CSS, 
  DaisyUI, 
  react icons,
  toastify

5 Key Features:

1. Interactive Plan & Saved Workouts Management: Tabbed UI interface allowing users to organize routines into "Today's Plan" and "Saved For Later" lists with instant action handlers (Mark as Done, View Details, Remove).

2. Real-time Fitness Analytics: Dynamic context provider calculating total exercises,  duration (minutes), and calorie burn totals updated instantly on user action.

3. Responsive Mobile-First UI: Optimized dark-themed layout built with Tailwind CSS and DaisyUI, featuring a smooth mobile navigation drawere.

4. Comprehensive Exercise Stats: Real-time aggregation of total planned metrics, automatically recalculating total workout time (minutes) and calorie consumption as items are modified.

5. Dual Workflows : Structured task separation that allows users to stash items in a "Saved" backlog or assign them directly to "Today's Plan" for immediate daily execution.
